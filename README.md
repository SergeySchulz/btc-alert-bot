# BTC/USDT Telegram-бот

## Запуск в PyCharm

1. Откройте папку проекта в PyCharm.
2. Откройте вкладку **Terminal** внизу.
3. Установите библиотеки:

   ```powershell
   pip install -r requirements.txt
   ```

4. Проверьте, что в `.env` заполнены `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
5. Откройте `bot.py` и нажмите зелёную кнопку запуска.
6. В Telegram отправьте боту команду `/start`.

## Кнопки

- **Рамки цены** — изменение нижней или верхней границы;
- **Актуальная цена** — общий курс и свежие цены активных бирж;
- **Биржи** — включение и отключение Binance, Bybit и OKX;
- **Уведомления** — включение и выключение сообщений;
- **Интервал** — проверка раз в 1, 2, 3, 4 или 5 минут;
- **Статус** — показ всех текущих настроек.

Выбранные настройки сохраняются в `settings.json` автоматически и остаются после перезапуска.

Общий курс рассчитывается как медиана цен включённых бирж. Это уменьшает влияние случайного отклонения цены на одной площадке.

При открытии рамок бот показывает актуальный курс. Редактирование можно отменить кнопкой без сохранения изменений.

Ключи Binance, Bybit и OKX для публичной цены BTC/USDT не требуются.

## Добавление пользователей с личными настройками

1. Новый пользователь открывает бота и отправляет `/start`.
2. Бот покажет его Telegram ID, но пока не даст доступ к управлению.
3. Владелец открывает `.env` и вместо одной строки:

   ```env
   TELEGRAM_CHAT_ID=111111111
   ```

   указывает все разрешённые ID через запятую:

   ```env
   TELEGRAM_CHAT_IDS=111111111,222222222
   ```

4. Бота нужно перезапустить.

У каждого разрешённого пользователя будут собственные рамки, биржи, интервал и состояние уведомлений. Изменения одного пользователя не влияют на остальных.
